# 手機版 Hero 主標置中調整計畫

日期：2026-10-09。分支：`codex/mobile-hero-title-center`。

## 目標與範圍

將首頁手機版 Hero 的品牌標題區水平置中。以圖標、SVG 主標「聆聽的河流」與副標「閱讀、復元與助人工作的書寫」作為一組對齊，保留現有字標比例、色票及垂直位置。已依使用者後續要求實作。

## 已查證現況

- codebase-memory-mcp 索引根目錄與分支符合目前專案，HEAD 為 `f6887dba`；已以 hero 關鍵字查圖定位，再讀來源確認。
- `layouts/index.html` 第一頁載入 `layouts/partials/river-home.html`；Hero 內的 `.river-brand-lockup` 包含 `river-wordmark.html` 與副標。
- `assets/css/river-home.css` 的 600px 以下規則將 lockup 寬度限制為 `min(100%, 330px)`，沒有左右自動 margin，因而依一般區塊排版靠左。
- 主標由 SVG 繪製，圖標與文字在內部各有定位；單加 `text-align: center` 無法移動整個字標區。
- 河線與兔子是獨立裝飾層。置中後的視覺平衡與重疊情況仍須瀏覽器驗證，不能僅由來源判定。

## 實作順序

1. 在現有 `@media (max-width: 600px)` 中，為首頁 Hero 的 `.river-brand-lockup` 加上 `margin-inline: auto`，讓整組以內容區中心對齊。
2. 為該組的 `.river-opening-subtitle` 設定 `text-align: center`；確認既有 padding、margin 不會偏移副標中心。
3. 保留 330px 上限、SVG 比例及 Hero 上下留白，先觀察 320／360／390／430／600px。較窄螢幕自然縮小，不強制超出可用寬度。
4. 以截圖確認河線沒有穿越文字、副標不碰兔子。若需調整裝飾，只處理手機斷點中的局部位置，另記錄前後差異。
5. 以 601／768／900／1440px 比較斷點與桌機，確認此修改只套用既有手機範圍。

## 驗收

- 以 lockup 外框為量測基準，左右留白差不超過 1px；SVG 文字本身因左側圖標而非獨立幾何置中，此方案的對齊單位是完整品牌組。
- 副標文字置中，主標無裁切、無水平捲動；明暗模式均清楚可讀。
- 兔子、河線與文字有留白，精選文章區起點與 Header 行為維持現況。
- 檢查低動態偏好與 200% 縮放的可讀性。
- 樣式實作後依 CONTRIBUTING.md 執行 Hugo 建置（獨立且忽略的輸出目錄），並執行 `git diff --check`；產物不提交。

## 取捨與回復

建議先採整組置中，以保留既有品牌構圖。若希望五個中文字本身對準螢幕正中央，需另調左側圖標與 SVG 內部配置，範圍更大，應以獨立試排比較。

回復時只撤銷本批手機斷點新增的對齊規則。保留既有未提交的腳本修改與本機產物；本計畫不包含提交、推送或部署。
