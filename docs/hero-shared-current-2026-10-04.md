# Hero：同向水色與溫潤紙面

取代 341aa06b 的 S 形發光河道。前版：https://645eaec7.listenriver.pages.dev/ 。

使用原本 river-current 的橫向 Bézier 路徑作為水彩色帶，同置於原有近景 SVG；線條與水色共用動畫及座標，不再各有一套方向。24 層不透明度 0.014 的細分描邊形成由中心向外變淡的水色，減輕分層邊界，沒有新增模糊濾鏡、動畫或圖片。

移除作用中的獨立河道 SVG、紙白光帶與額外回聲線。底色改為較沉靜的暖石紙 #F0E9DF / #EAE1D5 / #E5DACE，暖陶色 #B87E65 與灰藍 #65878D 僅作大範圍低對比暈染。主色帶 #668A91，深色模式 #87A4AA。保留細紙紋與原有文字對比。

桌面最小高度 380px；手機維持 280px。首頁其餘區塊不變，歷史材質保留供版本比較。原本 12s / 17s 動畫與減少動態效果設定沿用。

驗證：Hugo 建置成功；1440、808、390px 深淺模式無橫向溢出。瀏覽器核對色帶與主線路徑相同，動畫節奏及減少動態效果設定正常。已檢視桌面深淺色及手機畫面。
