## 第二批方向：六卡簡化與 tag 區（尚未實作）

- 六卡保留五類＋會所與既有目的地。先移除卡內細標籤入口，降低同一卡片的選擇層級；評估拿掉英文／編號等次要資訊、縮小卡片高度。既有描述若調整顯示方式，不重寫文字。手機目前已隱藏描述及標籤，因此主要收益在桌機，需分開看待。
- 首頁獨立 tag 區是可選方案，不預設新增。若只是把原本十五個卡內標籤平移成一大片 tag，入口數與重複選擇並未改善。
- 優先比較兩個預覽：A 為簡化六卡、不增 tag 區；B 為簡化六卡＋四至六個人工挑選的跨分類主題，以小型文字連結區呈現，不再加圖片卡或輪播。精選區與 Hero 均不動。
- B 可先沿用 `data/taxonomy-landing.yaml` 的 selectedTopics 作候選，逐項核對是否確實提供跨分類探索價值；不自動依篇數排名，不把會所三個系列或同名分類再列一遍。候選不等於最終核定清單。
- 若採 B，位置以六卡下方、最新文章上方作預覽；讓分類與跨分類探索相鄰，但控制高度。四至六個 tag 若加上一個標籤總覽，主題探索區最多 12～14 個目的地，低於原本 22 個；若無總覽則 11～13 個。
- 判斷標準：讀者能否透過 tag 找到六卡之外有價值的閱讀集合，以及新增區塊是否把最新文章推得太遠。若 tag 與主選單／分類入口高度重複，採 A 即可。下一步先看預覽再決定，不以「首頁一定要有 tag」為前提。

本計畫依使用者最新要求：先評估入口及首頁設計，不處理文案、分類導讀或會所導讀，不實作網站變更。前一份入口盤點的「文案／導讀優先」建議暫停，以本文件的入口配置順序為準。

## 判斷：需要減少同層選擇與重複內容

五類＋會所的六張卡片仍適合作為首頁地圖。問題集中在首頁同時放了分類、細標籤、精選文章、會所文章、最新文章與多個全站清單入口，且部分集合高度重疊。沒有必要因此減少分類或改動文章歸屬。

主選單與首頁分類卡的重複可以保留：主選單服務所有頁面的快速跳轉，首頁卡片服務初次探索。相較之下，同一頁相鄰兩區反覆呈現同一批文章，價值較低。

這是來源與建置輸出的設計評估，尚無點擊率、讀者測試或本輪瀏覽器截圖，不宣稱已證明讀者選擇困難或改版能提升轉換。

## 推薦方案 B：配置規格

以下是預計配置，不是已完成畫面。

```text
全站頁首：五類導覽／搜尋／作者等既有操作
品牌區：保留既有內容，檢視高度
探索主題：六卡＋分類總覽
精選文章：三篇
最新文章：六篇＋全部文章入口
作者資訊
圖集／頁尾
```

1. **六卡成為唯一主要分類選擇區。** 桌機以三欄兩列、手機以兩欄三列作預覽基準；保留卡片名稱與既有內容，不新增文字。將卡內十五個細標籤／系列連結移出首頁，這些目的地仍由分類頁、會所頁、標籤頁與既有主選單到達。主題區由 22 個目的地減到 7 個。
2. **先展示主題，再展示文章。** 主題區移至品牌區後，讓新讀者不用先越過精選輪播才看到全站範圍。精選保留三篇，桌機三張並列、手機採直列預覽，避免用另一個橫滑區承擔主要入口；是否太長由 390px 預覽確認。保留既有標題與摘要。
3. **會所文章併入全站最新。** 首頁保留會所主題卡與全站主選單的會所入口，移除獨立八篇文章區。全站最新仍按原本時間排序，不為了分類平均而排除會所文章。
4. **精選和最新各有用途。** 原本最多 8＋8＋6＝22 個文章展示位置，改為 3＋6＝9 個。這是展示位置減量，不是 22 篇不同文章變成 9 篇。後續實作可優先從不在最新六篇中的既有 featured 文章取三篇，以穩定排序選取；不足時顯示較少篇，不新增文章文案、不擅改 featured 歸屬。固定挑選規則在實作前於預覽標明。
5. **全部文章入口集中在最新區。** 移除精選區與作者卡指向相同全站清單的 CTA；作者卡保留原有作者與社群入口。移除按鈕屬入口調整，不進行文字改寫。
6. **總覽頁承接細分探索。** 首頁提供方向，分類總覽與分類頁保留細標籤。三個會所完整系列的主要入口統一導向 `/clubhouse/.../`；相關標籤仍可存在，但不作同一完整系列的另一個主要入口。一般文章標籤不全面改寫。

會所曝光是方案 B 最明確的取捨。如果後續確認會所必須是首頁主推內容，可在 A 的小型專區與 B 中二選一，不把兩個完整文章區重新全部加回。

## 手機與中間尺寸需要特別核對

首頁目前有 `home-mobile-topics` 與 `home-topics` 兩份結構；`custom.css` 與 `home.css` 有不同斷點的顯隱規則。最新文章也輸出桌機、手機兩份結構。不能直接把所有 DOM 連結加總當作手機實際可見入口。

實作第一步需在 390、480、481、768、1440px 檢查實際 computed display、順序及鍵盤焦點，特別確認斷點附近是否出現兩套入口同時可見或都消失。這是待驗證風險，並非本輪已重現缺陷。

方案 B 以同一份主題卡結構響應排版為目標，確認無引用與行為依賴後才移除重複渲染；不要只用 CSS 隱藏舊版而留下可聚焦元素。圖集先保留，不混入本批功能改造。

讀者任務：從首頁進任一主分類；從首頁進會所及任一子系列；找到最新文章；進全站清單；使用搜尋找特定文章。首頁進六大入口均一次點擊，會所子系列可經會所總覽兩次點擊；不要求所有細標籤都在首頁一次到達。

人工驗收需確認：分類卡比文章區更容易辨認；作者特色仍保留；全站最新不因去重而失真；移除的入口都有合理替代路徑。沒有分析工具資料時，以任務結果與前後畫面作決策，不承諾點擊率提升。
