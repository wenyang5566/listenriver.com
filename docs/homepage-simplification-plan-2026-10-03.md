# 首頁分階段簡化

目標：沿用暖色閱讀風格，逐步減少容器與卡片的視覺層數。每階段先在分支預覽確認，再進行下一階段。

## 第一階段：首頁大底板（已完成）

- 移除 `.home-discovery` 的背景與圓角。
- 共用 `.main` 的桌面表面樣式不再套用到首頁；分類、標籤與文章總覽仍沿用原有表面。
- 保留首頁欄寬、內距、間距及所有區塊排列。
- 保留首頁頭尾輪播、六張分類圖卡、最新文章及 Hero 動畫。
- 驗證：Hugo 建置成功；使用 Edge / Playwright 比對修改前後，1440、1024、390px 的深淺色模式下，首頁容器、直接子區塊及圖卡網格的位置與尺寸完全一致，頁面 scrollWidth 一致。
- 視覺確認：首頁外框已融入頁面底色，深淺色模式均移除大底板。

## 第二階段：首頁卡片與閱讀節奏（待預覽回饋）

- 先挑一種卡片減少框線、陰影與底色，評估文字與圖片能否自行建立層次。
- 一次只調整一種元件，先保留內容數量與網格排列。
- 若需調整留白，另作獨立變更，驗證手機與桌面斷點。

## 第三階段：分類與標籤頁（待第二階段定案）

- 逐頁盤點大容器、標題框、側欄框與文章卡片的表面層數。
- 先統一背景與表面色票，再決定哪些外框可以移除。
- 保留分類、標籤關係、文章網址與文章閱讀欄寬。

每一階段獨立提交，以便回退。正式站需待 PR 合併後才更新。
