## 目前專題與重複入口

本機現況有一個獨立會所區 `/clubhouse/`，使用專用版型；其下有實習、工作日誌、工作手冊三個子入口。聆聽疼痛計畫、正念的河流等目前主要使用 tag 入口，不是本次新建的獨立專題。先前建議新增這些專題只是提案，並未採用或實作。

會所同時有子區列表和同名 tag 列表；它們可能是不同網址呈現相近集合，應核對實際成員後選定主要入口。`content/clubhouse/_index.md` 的介紹仍稱來源為 tag「會所」，現有文章則使用「會所模式」等標籤，文案也須一併核實。

## 建議方案，等待討論

1. 保留五類，先寫分類介紹與邊界。回診心情屬病痛，日常不以長短或零碎程度定義；閱讀心得不必補上所有延伸意義的 tag。
2. Category 作主要歸屬；tag 可表示形式、具體主題或系列，但不用每篇填齊，不另新增三套 taxonomy。
3. 先整理 tag 字典與文章集合，分成保留、合併候選、只調整顯示、待確認；不按篇數或同名直接刪除。
4. 會所建議保留現有 URL 作唯一導讀頁，分類歸助人工作；實習／日誌／手冊保留在區內，不再把所有子入口都放進全站主導航。是否保留全站獨立連結待作者決定。
5. 不新增其他專題。系列 tag 已能支援聆聽疼痛計畫等內容，未必需要專用版型。

## 實作前交付顺序

1. 約 15–20 篇跨界文章試分表：主分類、必要 tag、理由，確認作者是否容易判斷。
2. 完整 tag 字典與合併候選表：列實際文章差集，不只列標籤名稱。
3. 導覽前後對照：五類、會所、橫向形式與系列各放哪裡，避免入口重複。
4. 最後定稿舊新 URL 映射，再開始實作。
