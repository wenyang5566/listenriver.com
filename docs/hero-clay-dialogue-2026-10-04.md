# Hero：陶土與紙的對話

比較基準：534b4852，https://dee4aee7.listenriver.pages.dev/ 。

本版將右側主色面從藍灰轉為陶土，讓暖色成為邀請對話的視覺重心；霧藍集中在右緣及底部，維持河流意象。閱讀留白採偏中性的燕麥紙，避免黃色過重。色面形狀、排版、河線動畫與下方首頁均沿用基準。

| 角色 | 色碼 |
| --- | --- |
| 紙面光線 | #FCF8F0 |
| 燕麥紙底 | #F5EEE3 / #F1E7DC / #E9DACE |
| 主標題 | #39494C |
| 小標陶土 | #984F3D |
| 內文暖灰 | #68615C |
| 主要陶土色面 | #E5C1AC / #D6A18B / #BD8069 |
| 邊緣霧藍 | #C7D1CB / #8DA7AA |
| 下方沉靜藍 | #819B9D / #56767E |

紙紋沿用靜態 SVG 細粒，淺色不透明度由 0.32 提至 0.46；以柔和的局部亮度模擬紙面受光，不增加動態濾鏡或 JavaScript。深色模式改為暖炭灰背景及低明度陶土，保留奶白字。

驗證：Hugo 建置成功；1440、808、390px 深淺模式皆無橫向溢出，河線維持 12s / 17s，減少動態效果設定下停止。已檢視桌面深淺色與手機淺色截圖。
