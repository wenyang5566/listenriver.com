# 首頁閱讀色票

主視覺參考暖紙質插畫的配色，讓閱讀空間保持柔和，也保留河流的藍色層次。色票目前用於首頁預覽，可供之後調整分類、標籤與文章葉面時沿用。

| Token | 色碼 | 用途 |
| --- | --- | --- |
| `--reading-paper` | `#F6F3ED` | 頁面自然暖紙底 |
| `--reading-surface` | `#FAF8F3` | 圖卡、列表與輪播文字面的微暖紙白 |
| `--reading-surface-soft` | `#EDE9E1` | 標籤的淡暖灰底色 |
| `--reading-line` | `#DED8CE` | 卡片與表面的暖灰邊線 |
| `--reading-accent` | `#986148` | 區塊小標、互動細節的陶土色 |
| `--reading-muted` | `#6E6860` | 摘要與次要文字 |
| `--reading-ink` | `#3E4B50` | 主標題與主要文字 |
| `--river-blue` | `#64899B` | 河流主線、連結等冷色重心 |
| `--river-mist` | `#7E9DB0` | 淡霧藍背景色塊 |
| `--river-sage` | `#668779` | 左上品牌標誌，白字 |
| `--river-ochre` | `#D8BB80` | 河線的柔和暖黃層 |
| `--river-sand` | `#B9A58A` | 淡砂棕遠景線 |
| `--river-clay` | `#BD8065` | 少量陶土色細線 |

以暖紙與閱讀墨色為主，藍色和鼠尾草綠保留品牌層次，陶土與暖黃作點綴。首頁各類卡片統一沿用閱讀表面，避免硬編碼的亮白底。

2026-10-04：依預覽回饋降低首頁下方區塊的黃度，改用接近自然紙張的微暖白與暖灰。Hero 保留試作 D 配色，右上圓形改為向外透明淡出的徑向漸層；深色模式同步柔化邊緣。

深色模式使用紙底 `#282A29`、表面 `#353530`、柔和表面 `#414038`、邊線 `#625B4F`、暖色點綴 `#DFB08A`、次要文字 `#BCB0A0` 與主要文字 `#F5EADA`；河流與品牌仍有各自的深色對應值。
