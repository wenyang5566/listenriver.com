# 社工作者定位與分類系統建議

日期：2026-10-13。接續[全站評估](../site-awards-readiness-audit-2026-10-13.md)，依使用者補充「作者是社工」提出建議。本輪不改文章分類、網址、導覽或發布。

## 判斷

五個主分類本身不算太多，文章實際重疊也很低。226篇文章的五類合計227次歸類，只有一篇跨兩類。比較需要整理的是：會所專區與主分類的層級、格式與主題混在標籤中的角色，以及少數高度重疊或名稱近似的標籤。

名稱相近不代表內容重複，文章在分類和專題都出現也不自動是問題。讀者若能理解「這是全部助人書寫」「這是其中的會所系列」，就是有用的不同入口；兩個近乎相同的電影列表卻沒有說明差別，才會造成選擇成本。

## 1. 社工是作者視角，五個方向是書寫範圍

建議定位文案：**「一位社工，從自身病痛、閱讀與工作現場，書寫理解與陪伴。」**

這能將社工、病痛、閱讀與日常連成同一個作者，不必把所有文章改寫成專業知識文。保留第一人稱、困惑與生活細節；社工身份在首頁副標、作者介紹及代表選文中清楚出現即可。既有字標與兔子不需重新設計。

「助人工作」可先保留名稱，介紹改以「社工的學習、實踐與現場反思」清楚界定；如果之後測試發現讀者仍不知道作者職業，再比較「社工與助人」的顯示文字。名稱變更須另外核定，不能順手改taxonomy key與網址。

首頁優先策展一條「從自身經驗到理解他人」的3–5篇路線，讓作者身份透過作品成立；不用在五類之前再建立一套競爭性的分類。

## 2. 保留五類，把邊界說清楚

| 主分類 | 主要回答的問題 | 建議的歸類依據 |
| --- | --- | --- |
| 閱讀筆記 | 我從一本書、一部電影或一堂課讀到了什麼？ | 文章主體在外部作品／內容的整理或回應 |
| 助人工作 | 我在社工學習與現場，如何理解、陪伴、一起行動？ | 主體在助人關係、工作方法與實踐反思 |
| 病痛經驗 | 疼痛如何被經歷、說出與聽見？ | 主體在身體、就醫、病痛敘事及他人的經驗 |
| 成為自己 | 我如何面對情緒、關係、選擇與自己的變化？ | 主體在自我理解及關係中的成長 |
| 日常書寫 | 生活與創作讓我看見什麼？ | 主體在生活片段、畫畫、靈感與日常觀察 |

「閱讀筆記」是偏材料來源的分類，其他較偏書寫視角，分類軸並非完全一致；但這是一個長期個人刊物，清楚的實際使用規則比全面重分更有價值。先規定以文章的主要關注點歸類，確有需要才第二分類，不為了涉及一本書就同時歸入閱讀、也不因作者是社工就全歸助人。

例：創傷知情工作坊文章若主要談陪伴與實務，放助人工作，另標「講座心得／創傷知情」；電影文章主要談作品，放閱讀筆記，另標「親密關係」。這些是後續編輯規則，不是本輪已搬動文章。

「成為自己」與「日常書寫」概念邊界較柔軟，先核對各10篇邊界文章與導讀，再看新讀者是否分得出來；目前沒有足夠證據支持直接合併它們。

## 3. 會所是專區，與助人工作的重疊合理

會所30篇全部屬於助人工作56篇中的一部分，其餘26篇為其他助人書寫。建議維持兩個入口，但說清楚：

- 助人工作：跨場域的學習與實踐，包含會所文章。
- 會所專區：特定工作場域的完整系列，含工作日誌、實習紀錄與工作手冊。

首頁原六張入口可保留，將會所標為「專區」，分類總覽繼續說明「五個書寫方向＋會所專區」。它是值得突出的代表內容，不必為了互斥而從助人工作排除。

先維持現有導覽位置並標明角色；後續若需要更精簡，可比較「文章分類」集合五類、另設「專題」集合會所／聆聽疼痛計畫／素描的導覽原型。這是替換導覽分組的候選，不能在原六個入口旁又加一整排同樣目的地。

「書摘」與「閱讀心得」是值得保留的類型區別。同一本書可以有兩篇不同文章；可在該書入口並列「原文摘錄／我的回應」，不合併正文與網址。這種對話恰好能呈現社工作者如何把閱讀帶回自身和現場。

41個tag不是必須砍成某個固定數字的問題。主導覽只展示少量有清楚用途的入口，細標籤放在文末與索引。7個單篇tag先檢查是否為重要書名、人物或概念，不因只有一篇自動刪除；英文拼字與同義名稱另核對。

## 5. 讓讀者只面對兩種主要找文方式

對讀者呈現「按書寫方向找文章」和「讀一個完整專題」。格式篩選與細標籤留在各頁內，不把分類、標籤、系列、策展路線全部升為同級選單。

內部維持四種責任即可：主分類是書寫方向；書摘／心得等是文章類型；創傷知情／親密關係等是跨分類主題；會所日誌／疼痛計畫／素描是有特定集合或順序的專題。無須立即新增四種資料欄位或重建CMS，先把顯示名稱與頁面說明分清楚。

首頁／About的作者選讀是編輯推薦，不必變成新的固定分類。文末依文章角色給一個主要續讀目的地，避免同一目的地以分類卡、tag卡與系列卡重複出現。

## 6. 實作次序與驗收

1. 先把社工身份與五類邊界寫成短文案，會所明標專區；保留原六卡與網址。
2. 核對電影33篇與講座12篇的聯集，整理主要入口及同義詞；先做呈現層簡化，再核定是否需要taxonomy遷移。
3. 為疼痛計畫與素描補緣起／完整目錄／閱讀順序；接上既有作者導讀，先完成一條推薦路線。
4. 用5位初訪者測三個任務：找一篇電影心得、找會所工作日誌、找作者自己的病痛書寫。若多數人能在首次選擇到達正確入口，且能說出助人工作與會所的差別，再擴大調整。

本輪沒有讀者測試，不能把內容集合的低重疊等同於讀者一定不困惑。建議中的入口合併也不能替代搜尋漏召回的修復。
