## 觀察與取捨

兩張參考共同使用耳朵、彩色捲曲線；第二張加入葉片並橫向展開。將曲線解讀為聲音、河流與蕨芽是本次設計詮釋，並非手稿作者的文字說明。第一張的直立生長感適合獨立識別；第二張的橫向延伸適合 hero。

完整插畫以開放耳廓承接主河線，分出少量支流；葉片附著耳後，形成一個整體。線條使用圓端與粗細層級，取消具象耳內陰影與高飽和螢光色。小圖示另繪簡化骨架，避免將完整插畫直接縮小。

依使用者「更簡單易懂」的回饋，圖示第二版移除枝芽與末端漩渦，收斂成耳廓和向外舒展的河線。兩條 SVG path 不交疊，耳廓在河線出口留出間隔；線寬由 3 增至 3.5，使用兩色或單色均可。以 Edge 實際渲染檢視 24／32 px 和單色版；獨立預覽的頁首與图示展示同步更新。完整 hero 插畫維持原設計，正式首頁尚未套用。
