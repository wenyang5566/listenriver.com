## 設計方向

溫暖的書刊編排：奶油紙色、深棕文字、陶土與河青點綴，搭配自然曲線與充足留白。以閱讀、書寫、復元與助人工作的親近感為核心；專業感來自清楚層級、對齊與節制的細節。

照片與內容是主體。大面積維持紙色，分區主要靠留白與細分隔線；避免把每個區塊都做成浮起的卡片。曲線保留手稿的呼吸與回旋感，但不能穿過正文或壓低文字辨識度。

## 字體與文字層级

首頁內容字體序列：`PingFang TC → River Sans → Noto Sans TC → Source Han Sans TC → Microsoft JhengHei → sans-serif`。`River Sans` 是本機網站資產 `/fonts/river-sans.woff2`，使用 `font-display: swap`。

Header 是獨立的書刊字標：`Noto Serif TC → Songti TC → PMingLiU → serif`。目前是系統 fallback 序列，沒有額外載入專用宋體字型，各平台字形可能不同。

| 項目 | 目前規格／辨識原則 |
| --- | --- |
| Header 字標 | 桌機 21px／600，行高 1.3、字距 .1em；640px 以下 17px，360px 以下 16px |
| Header 字標內容 | 五個字大小、字重、顏色一致；保留底部細河線，使用者要求先維持此版本 |
| Hero 主標 | SVG 字形；不是單靠 h1 的 font-size 決定外觀。不可將 Header 字標替換成這組大字 |
| Hero 副標 | 桌機 17px／400、行高 28.8px；手機 14–15px、行高 24px |
| 精選摘要 | 桌機 16px／行高 1.85；手機 15px |
| 次級故事標題 | 桌機 21px／行高 1.6；窄版降至 20／19px |
| 次級故事摘要 | 桌機 14px／行高 1.8；手機 13px |

## Header 與 Hero 的分工

Header：正式 Logo ＋精簡宋體字標，上層品牌靠左、功能按鈕靠右。桌機下層分類選單整組置中，主要間距 24px，900px 以下縮至 12px；手機保留抽屜選單。Header 字標細河線寬 1、透明度 .65，不增加額外枝葉。

Hero：較大的 Logo、SVG 主標、副標、延伸河線與兔子形成同一幅構圖。桌機主標向左微調 9px；副標依文字可見左緣做光學對齊，最後位置已經使用者反覆調整，不重新套用粗略百分比置中。

正式 Logo 保留原始幾何：主線寬 3.5、小弧 2.8（SVG viewBox 座標）。Hero 的 Logo 插畫處理為 2／1.6，不能回寫正式 Logo 資產。這些是不同 SVG 座標系統中的線寬，不代表畫面上的固定 CSS px。

Hero 背景主水線 1.35／透明度 .38，岸線 1.1／.24，水紋 1／.45，色池 .045；遮罩、漸層與群組透明度會進一步影響實際濃淡。保持「主標附近較明確、背景水紋較淡」的層級，不為了填滿空白一直加線。

兔子圖形、位置和比例保留。延伸線不穿越副標文字；使用者曾否決加強包覆副標的版本，沿用較自然、保持留白的版本。

## 排版、元件與動態

- 主容器以 1280px 與桌機側邊 48px 為基礎；響應式另有縮減與寬螢幕規則，延伸頁面需核對最終 cascade。
- 桌機圖文並列、手機轉為直向閱讀；不要只縮小整個桌機畫面。
- 圖片使用輕圓角，區塊避免厚邊框與大量陰影。小型操作常用 44px 圓形按鈕，保持點擊範圍。
- 分類與小標使用陶土色；正文保持深棕或暗色模式的暖白。
- 主河線保持安定，水流軌跡緩慢移動，現況週期 24 秒。進場線條約 2 秒；支線 Hover 只有極小角度變化。
- 遵循 `prefers-reduced-motion`，不要把閱讀頁背景做成持續吸引注意的動態舞台。
- 首頁 Header 持續置頂；文章頁維持向下隱藏、向上顯示。選單開關須保留捲動位置與鍵盤焦點；捲動鎖定需覆蓋 860px 選單斷點。

## single 文章頁的延伸建議（尚未實作）

承接色彩、Header、字體與留白節奏，將視覺中心交給文章標題和正文。首頁 Hero 構圖不直接複製到每篇文章。

1. 背景採紙色，正文採主文字色；日期、閱讀時間採次文字色，分類與連結採陶土強調。暗色模式使用對應色票，不以濾鏡反轉。
2. 桌機正文建議先試 680–740px 寬、18px 字級、1.9–2.0 行高；手機先試 17px 與 20–24px 側留白。這是試排起點，須用長文、引言、清單與圖片驗證後決定。
3. 文章主標建議保留內容字體，桌機先試 32–40px、手機 26–30px；長中文標題允許自然換行，不能沿用首頁 SVG 主標或強制單行。
4. 頁首可用一小段淡河線連結分類與標題區，正文區保持乾淨；兔子留在首頁，不自動加入文章。
5. 引言以細陶土邊線與淡底色呈現；圖片註解使用次文字色。分隔線維持 1px，相關文章延續首頁的輕圖文編排。
6. 下一篇／上一篇、目錄、分享與互動按鈕採相同色票、焦點與操作尺寸；閱讀功能優先於裝飾。
7. 實作先做共用語意 token，避免在 single 複製整份 `river-home.css`。首頁色票目前 scope 在 `body.river-home`，不能假設文章頁已取得這些變數。

延伸驗收：桌機／手機、亮／暗模式、長標題、純文字長文、直橫圖片、引言、清單、程式碼／表格，以及 Header 選單與鍵盤操作。保留文章結構、既有網址與閱讀功能。
