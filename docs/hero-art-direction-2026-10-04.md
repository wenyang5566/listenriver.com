# Hero 視覺規格：紙上對話

## 設計意圖

參考使用者提供的四張插畫：大面積暖紙留白、藍灰與藍綠的沉穩色面、少量陶土暖色，以及霧面的纖維質感。把這些特質轉成抽象的河岸與紙張拼貼，讓文字保持清楚、讓色彩有各自的位置。

閱讀區使用暖紙色與深墨藍；畫面右側集中藍灰、陶土與深藍色面。暖感由紙底與陶土提供，藍灰負責平衡。避免將黃與綠大面積疊成混濁的底色。

## 淺色配色

| 用途 | 色碼 | 視覺角色 |
| --- | --- | --- |
| 紙底 | `#F9F3E8` → `#F4EBDC` → `#ECE1CE` | 全幅自然紙張底色 |
| 主標題 | `#304B55` | 深墨藍，穩定閱讀重心 |
| 小標 | `#A15D43` | 陶土色，少量暖色提示 |
| 內文 | `#65635C` | 中性暖灰 |
| 藍灰色面 | `#C0CBC7` → `#86A3AA` | 右側主色面 |
| 陶土色面 | `#DCAC92` → `#C78367` | 靠右的暖色回應 |
| 深藍色面 | `#688B93` → `#456875` | 右下方的視覺重量 |
| 亞麻紙片 | `#E2D6BF`、`#F0E5D1` | 連接紙底與較深色面 |
| 河線 | `#547D85`、`#B8795D`、`#BCA57B`、`#8DA6AC` | 延續各色面，不另加新色系 |

桌面配置以暖紙留白為主，約三分之一的右側有較明確的顏料色面。此比例是構圖方向，不是固定面積限制。

## 材質與實作

- `static/images/hero/mineral-paper.svg`：抽象色面，用非對稱曲線與透明遮罩形成疊紙層次。
- `static/images/hero/mineral-paper-dark.svg`：深色模式專用色面，以炭灰、沉穩藍綠與低亮度陶土色組合。
- `static/images/hero/paper-grain.svg`：192px 可重複平鋪的靜態細粒與纖維；使用向量短線，沒有即時噪聲 filter。
- 顏料在 Hero `::before`，紙紋在 `::after`，文案位於上層；装飾均不攔截點擊。
- 每個模式使用一張 1,465 bytes 色面 SVG 與共用的 16,309 bytes 紙紋 SVG；約 18KB 未壓縮資產。沒有新增 JavaScript、動畫或大幅點陣圖。
- 深色模式採較低紙紋透明度，避免黑底顆粒太強。
- 手機的右側色面降低透明度，並以線性遮罩逐步淡入，避免裁切直線和文案競爭。
