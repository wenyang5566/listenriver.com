# 首頁、分類與主題：設計及入口整理評估

日期：2026-10-03。基準：`codex/hero-flow-evaluation`，`33128bbd`。

## 結論與定位

建議發展成「有河流識別的文字刊物」：以中文排版、編輯節奏、清楚的閱讀路徑與細緻互動提高完成度。沿用 Hugo、PaperMod、Pagefind、五分類與會所專區，保留已接受的六條 hero 水紋。首頁六入口保留，但移除入口內的次級岔路。

主要問題是入口分工及呈現重複；目前證據不足以支持全面重分文章或合併 taxonomy。先整理介面，再以文章集合比對決定是否需要資料治理。

Awwwards／FWA 作為設計企圖心與品質參考，這份評估不等於獲獎機率或評審分數。Awwwards 官方得獎頁呈現 Design、Usability、Creativity、Content 四面向；本案將其轉為視覺一致、找文清楚、河流識別及作者內容品質。FWA 官方 About 本次未取得可讀正文，不引用其精確評分規則。

| 最近文章重複進入完整清單 | 分類 605、620；tag 1914、1939；瀏覽器確認閱讀筆記及開放式對話的前三標題重複 | 移除獨立「最近文章」區，保留一份完整清單與分頁；避免排除前幾篇造成檔案庫缺項 |
| 主題頁相關分類重複 | 開放式對話標頭 chips 與桌面右欄皆有閱讀筆記、助人工作 | 只留一處小型相關分類，相關主題放清單下方，先呈現文章 |

不是所有重複都要刪：全站導覽與首頁六入口可以共存，前者幫熟客跳轉，後者提供介紹。也不能把原始碼有兩個 home topics partial 就視為雙重可見：390px 實測 home-mobile-topics 為 display:none，只有另一套分類區可見。

## 資訊架構契約

| 層級 | 讀者問題 | 內容角色 | 主要出現位置 |
| --- | --- | --- | --- |
| category：五方向 | 想讀哪一類書寫？ | 穩定的大方向，沿用既有分類 | 首頁六入口、分類總覽、導覽 |
| tag：具體主題 | 想繼續追哪個題目？ | 跨分類交集，也包含形式、人物、作品等不同維度 | 主題總覽、文章與內頁延伸 |
| 會所／系列 | 想連續讀哪組紀錄？ | 沿用專區與系列目的地 | 六入口中明示「專區」；專區內才展開系列 |
| 搜尋 | 已經知道關鍵字 | 精確尋找與探索補充 | 所有頁面固定可達 |

tag 不宜假扮 category 的嚴格子類：例如開放式對話橫跨閱讀筆記及助人工作。下拉選單若保留 tag，需標示「延伸主題」，不能讓點擊跨分類集合卻像在本類篩選。

名稱相近只列為待查：電影／電影心得、講座／講座筆記／講座心得、聆聽疼痛／聆聽疼痛計畫。這些可能代表不同語意；需比對文章集合、導讀及網址使用後再決策，不直接合併、改 slug 或刪 tag。

## 各頁提案

### 首頁：定位、選方向、開始讀

順序建議：既有河流 hero → 六個閱讀入口 → 最近文章五篇 → 初訪推薦最多三篇 → 簡短作者介紹。

- 六入口保持現有內容目的地；五類與會所同區但會所標「專區」。每卡只保留名稱、一句介紹、目的地；篇數可作輔助，移除卡內 tag。
- 最近文章採完整標題、日期、小型分類標示，摘要最多兩行，封面可選。新版先以六入口在前，與 10/2 最新文章優先草案不同，是本輪針對分類混乱的建議。
- 初訪推薦使用既有 featured 或已有導讀，固定排序與一句理由；不用 shuffle 取八張大圖。作者不必定期策展。
- 圖集退出首頁主閱讀路徑，評估移至關於作者；保留原始圖片與內容。這是待實作提案，沒有移動資料。
- 全站導覽先採「閱讀分類／主題索引／關於／搜尋」，閱讀分類下保留既有五類及會所專區；取消第二層 tag 與第三層系列。站名提供返回首頁。相較直接攤開五分類，多一步但更清楚，需用找文任務比較驗證。

### 分類總覽：安靜的目錄頁

短導言 → 五類＋會所六入口 → 一個主題索引連結。去掉精選 tag 圖卡與完整 tag 雲。桌面目錄區可寬至約 1100–1200px，導言文字維持較窄行寬；手機單欄或寬文字列，不用橫向拖曳找入口。

### 分類內頁：介紹與一份文章檔案庫

分類名與短介 → 既有導讀／推薦 → 一份按年份文章清單及分頁 → 單一相關主題區。

閱讀筆記已有三篇作者推薦，應重新排版，不另寫一套。長篇導讀可用「閱讀完整介紹」漸進展開，文字保留且鍵盤可操作。拿掉自動最近三篇區與「其他主分類」固定侧欄，跨分類切換交給全站導覽。病痛分類的聆聽疼痛計畫分流已有特殊邏輯，須保留並單獨驗收，不能用通用模板抹平。

### 主題總覽：可掃讀的索引

「主題索引」＋一句說明 → 至多六個推薦主題文字連結 → 全部主題與篇數。

全部主題是唯一完整 tag 清單；預設採穩定名稱排序、可切換篇數排序。可加本頁即時篩選，標明「篩選主題名稱」，與全站文章搜尋分清楚。若沒有 JS，完整連結仍能閱讀。不必再按五分類把所有 tag 分組，避免把跨分類主題重新偽裝成子分類。

### 主題內頁：直達相關文章

主題名稱、篇數、一至兩句既有介紹 → 一份文章清單 → 最多三個相關主題與相關分類。

九篇的開放式對話頁直接列九篇，去掉三張「最近文章」大卡。書籍、作者、概念等 tag 共用輕量版型；只有真正系列使用既有系列入口。相關主題以交集／編輯相關性選取，而非只沿全站熱門順序取前十。

## 視覺品質與動態規則

1. 統一格線、頁首尺度、麵包屑及清單排版；現在首頁寬、分類總覽窄、內頁又大面積卡片，節奏缺少一致性。
2. 暖白與青綠保留；減少卡片裡再套卡片、重陰影、英文大寫標籤與過多裝飾性小字。
3. 以完整中文標題、段落留白和細分隔線建立閱讀節奏。封面不再決定每個入口的尺寸與吸引力。
4. 保留 hero 雙向水紋作識別；其他頁只沿用静態線條、色彩與小幅 hover/focus。使用者減少動態偏好與暫停維持有效，不把動畫鋪滿文章清單。
5. 分類色只輔助辨識，不為六入口新增六套視覺世界。文字版也須完整成立，不要求作者持續製作封面。

這些是設計提案，不是已取得讀者成效的結論。目標是清晰而有辨識度的閱讀體驗，不能以增加特效数量作為達到獎項等級的證明。

## 實作順序與驗收

**第一批：入口減法。** 統一用語及順序；分類總覽移除完整 tag 與精選主題圖卡；分類／tag 內頁只留一份文章清單；相關入口只留一處。先不更改文章集合、slug、aliases。

**第二批：首頁編輯節奏。** 六入口一張卡一個目的地；精選改固定三篇、縮小圖片；調整首頁次序與全站導覽。保留 hero 成果。

**第三批：視覺與主題索引。** 共用字級、間距、清單及寬度；主題名稱篩選、少量微互動。先做首頁／閱讀筆記／開放式對話三個樣本，再推廣。

技術影響集中在 layouts/index.html、partials/header.html、site-nav-items.html、home-topics.html、featured-banner.html、taxonomy-content.html 與相關 CSS。taxonomy-content 同時處理總覽和內頁，應先局部改分支，不在同一批全面重寫；入口顯示資料再逐步統一至 data，避免幾份排序與名稱各自維護。

驗收條件：

- 每卡一個主目的地；每個 taxonomy 頁只有一份主要文章清單；每頁只有一個相關主題區。
- 全部 tag 仍可從 /tags/ 找到，少篇數 tag 不被刪除；舊文章及 taxonomy URL 保持可達。
- 確認 390／768／1440px、明暗、鍵盤及 reduced motion；長標題不被裁切，手機不必左右拖曳才能選主入口。
- 按 CONTRIBUTING 建置、URL guard 及與變更相關的現有驗證；特別驗收病痛系列分流和會所連結。
- 邀讀者完成「找閱讀心得」「找開放式對話全部文章」「找會所工作手冊」三項任務，記錄路徑、誤點及是否能說明分類和主題的差別。目標從首頁最多兩次點擊到分類／主題／系列目的地；實測前不聲稱達成。
- 固定裝置及內容比較首屏可見入口、文章清單前高度和載入指標。沒有量測前，不宣稱效能或停留時間改善。
