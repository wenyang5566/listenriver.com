# Hero：薄紙透光、水彩暈染

前版：9119b9e4，https://4295ca00.listenriver.pages.dev/ 。

移除拼貼色塊的硬邊，改用橢圓放射漸層疊色，讓陶土與霧藍逐步消散。中間斜向暖白光帶形成透光薄紙感，保持左右閱讀區與色彩區的連續性。

- 紙底：#FDFAF3 / #F7F1E8 / #F5EEE5 / #F0E8DE。
- 陶土：#C88973，中心不透明度 0.62，向外降至 0。
- 霧藍：#789DA5，中心不透明度 0.58，向外降至 0。
- 透光：#FFFAF1，斜向柔和留白，避免暖冷色直接混濁。
- 紙紋不透明度由 0.46 降為 0.23；深色 0.12。
- 河線不透明度近景 0.30、遠景 0.19；動畫路徑與速度維持原樣。
- 深色模式使用暖炭紙底、#BC8870 陶土與 #71929B 霧藍。

SVG 為靜態漸層，無模糊或即時噪聲濾鏡、無新增 JavaScript。色霧覆蓋整個 Hero，避免中途裁切形成垂直分界。手機降低整體色霧不透明度至 0.7。首頁其餘區塊不變。

驗證：Hugo 建置成功；1440、808、390px 的深淺模式無橫向溢出。河線維持 12s / 17s，減少動態效果設定正常。已檢視桌面深淺色與手機淺色畫面。
