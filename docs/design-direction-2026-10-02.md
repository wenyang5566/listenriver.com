# 聆聽的河流：以社工文字書寫為核心的設計計畫

日期：2026-10-02，修訂版，取代同日原計畫。作者是社工，以文字書寫為主。所有網站實驗在獨立 worktree 進行。

## 1. 核心修正

主角是作者的文字、生命經驗與工作反思。目標是容易找文、舒服讀完、方便續讀，而且作者只要繼續寫文章就能維持網站。

Awwwards 僅作為排版、易用性與細節品質的參考；FWA 是可選創意參考，獎項與展示互動不列為驗收目標。電影展示網站不再作為主要版型參考。

取消原案中的必要工作：大型品牌影像、六類藝術封面、每期圖像策展、河流互動地圖、額外拍攝素材。河流意象留在既有色彩、細線與語氣即可。

保留五分類、首頁六入口（含會所）、文章 URL、既有內容與作者語氣。沿用 Hugo／PaperMod／Pagefind，小批次調整。

## 3. 各頁計畫

| 區域 | 調整 | 作者維護成本 |
| --- | --- | --- |
| 首頁 | 簡短站名與定位、最新文章文字清單、六入口、初訪推薦、作者介紹 | 最新文章自動更新；推薦長期有效 |
| 分類總覽 | 名稱、一句既有說明、篇數與清楚文字連結；不要求圖片 | 沿用既有資料 |
| 分類內頁 | 短導言、既有推薦、相關主題、全部文章 | 不強制每類補齊推薦或新文案 |
| Tag 總覽 | 「主題總覽」文字索引優先；篇數輔助；標籤搜尋列第二批 | 從現有 tag 自動生成 |
| Tag 內頁 | 主題名、簡介、文章清單與相關分類；少篇數時省略最近文章區 | 不強制每個 tag 都寫導讀 |
| 文章 | 優先改善中文字級、行距、行長、段落、引文、連結、續讀 | 不改原文、不要求封面 |

### 首頁草案

1. 聆聽的河流，加一至兩句自我介紹。提案文案：「我是文揚，一名社工。在這裡寫下閱讀、病痛、助人工作，以及成為自己的過程。」實作前確認作者希望公開的表述。
2. 最新文章 5–6 篇：完整標題、日期、分類、閱讀時間與最多兩行摘要。摘要沿用 description／summary，沒有合適摘要就省略。
3. 五分類＋會所六入口：文字卡或清楚列表；桌面兩至三欄，手機依字數使用單欄，不以截斷標題維持高度。
4. 「第一次來，可以從這裡開始」：最多三篇長期推薦，沿用已有導讀；不隨機、不要求定期換刊。
5. 簡短作者介紹與關於連結；既有圖集降為可選段落。

最新文章與初訪推薦的次序可在原型比較；主要入口不依賴輪播、拖曳或 hover。

### Category／tag 分工

分類回答「想讀哪類書寫」，tag 回答「追哪個具體主題」，會所與系列提供連續阅读路徑。保持現有內容結構，不重分文章。

同名分類與 tag 在介面說清楚，例如「助人工作分類」「跨分類主題：助人工作」，不逕自合併網址。系列沿用既有目的地。分類內 tag 若顯示本類篇數、點擊後卻到全站集合，需明確標示。

## 4. 閱讀視覺規格（待原型驗證）

- 沿用既有青綠與暖白，減少多層容器、陰影及漸層。
- 先改善現有中文字體的比例、字重與行距。特殊字體僅為選項，加入前確認授權、下載量與顯示品質。
- 正文起始試驗：桌面 18–20px、手機 17–18px，行高約 1.8–1.95；桌面約 36–40 個中文字寬。以真實長文、書摘、列表與引文校正。
- 日期與 tag 仍須清楚可讀；連結與鍵盤 focus 明確，點擊區以 44px 為目標。
- 列表允許無圖；文章原圖保留，長標題、圖片說明與引用完整呈現。
- 不自動輪播、不接管捲動；基本 hover／focus 即可，支援減少動態偏好。
- 作者發文不需增加設計欄位、製作卡片或挑選封面。
