## 核心判斷

網站已有清楚的個人書刊識別：紙色／暖棕、宋體字標與河線、兔子、真實工作與閱讀照片。Header、首頁與新版分類列表已形成可保留的基礎。以追求獎項作品的完整度來看，現在仍是「有個性的內容網站」，尚未形成全站一致、可辨識的互動閱讀體驗。

下一輪不再優先調 Header；優先補操作缺口、統一全部文章列表、重整關於頁構圖與搜尋摘要，最後加強有內容目的的品牌互動。不要把加入 WebGL、大型動畫或換框架當成品質提升的前提。

本評估是設計判斷與工程查證，不是官方評審分數，也不預測獲獎。Awwwards 的官方作品評分頁呈現設計、易用性、創意、內容四個面向；本評估以此分類。[官方評分頁範例](https://www.awwwards.com/sites/acme)。FWA 官方自述重視創意、原創性與技術品質，本評估以品牌互動能否服務內容來對照，沒有套用虛構的 FWA 配分。[FWA 官方介紹](https://thefwa.com/FWA25/25.html)。本輪 Awwwards about-evaluation 與 mobile guidelines 直接讀取超時，未聲稱已完整讀取其最新評審規章。

## 已確認的功能／品質缺口

### P0：燈箱鍵盤焦點

在正念文章 `.post-content img[role="button"]` 聚焦後按 Enter，lightbox 有開啟，但 `document.activeElement` 仍為背景圖片；按 Tab 後焦點仍在 dialog 外。這是本輪實測，不只是來源推論。

`static/js/custom.js:946` 的 openLightbox 沒有移入焦點；closeLightbox 也沒有回到觸發點；keydown 處理 Escape／箭頭，但缺少 Tab 範圍控制。建議補開啟焦點、Tab／Shift+Tab 限制與返回焦點，再驗證手機和 reduced motion。完成標準：開啟後焦點位於 dialog、背景不再可 tab、Escape 返回同一張圖片。

### P0：內頁 skip link

`layouts/_default/baseof.html:25` 只在首頁輸出跳至閱讀內容；main id 同樣只在首頁。文章、列表與關於頁鍵盤使用者不能直接跳過共用 Header。建議擴為全站一致的 skip link 與 main 目標，驗收首次 Tab、啟用後焦點與目標不被 Header 擋住。

### P0：舊圖示資源缺失

掃描完整產物 612 份 HTML、32,553 次站內 href 參照，五個目標在本機產物不存在：`/favicon.ico`、`/favicon-16x16.png`、`/favicon-32x32.png`、`/apple-touch-icon.png`、`/safari-pinned-tab.svg`。每個被 355 份頁面引用。來源為 `layouts/partials/head.html:94` 起的預設路徑；extend_head 另有目前可用的 PNG favicon，不代表其餘引用有效。

建議配置現有品牌圖示的正確路徑，並補齊適用的多尺寸／apple-touch 資源或移除無效宣告。驗收完整產物 href 不再指向缺檔、HTTP 200 與手機加入主畫面圖示。

這輪沒有發現缺少本機目標的文章 href；掃描排除了 script 內 JSON 與外部網址，未檢查 fragment id、src、正式站轉址、外部連結或人工內容語意，不能宣稱全站所有連結皆正確。

## 建議實作順序與驗收

1. **操作與產物完整性**：燈箱焦點、全站 skip link、圖示引用。先消除可重現問題，保留所有內容 URL。
2. **全站視覺一致性**：先把 `/blog/` 改成共用 archive 語言，再做關於頁。驗收手機／桌機／明暗模式、無封面／長標題、分頁及返回位置；保留既有分類與文章集合。
3. **找文與續讀**：精修搜尋摘要；工作日誌等系列以明確 series/order 或資料清單提供上一／下一篇。驗收連續三篇系列、跨系列不誤接、零結果及返回搜尋位置。
4. **品牌體驗**：選一個有內容目的的入口，例如「沿著正念的河流，從三篇文章開始」，讓河流意象與一條策展閱讀路線結合。用清楚連結、少量過場與 reduced motion fallback；不增加讀者負擔。這是創意提案，尚未實作。
5. **效能證據**：固定首頁精選樣本、三次手機／桌機冷載入，量測 LCP 元素、CLS、互動、字型與圖片傳輸，再決定 CSS 或圖片優化。

建議下一批先做 1，再做 2 的全部文章頁。Header 本體可保留目前定稿。完成以上後再評估是否具備 Awwwards／FWA 提交作品的整體一致性與原創體驗，不承諾獲獎。

本評估文件隨 Header 定稿交接提交；本輪未部署或改動網站功能。Header 維持 e088b3c7，不再增加厚度與動畫調整。下一批先處理操作與產物完整性，再統一全部文章列表。另行輸出的 Facebook 封面為首頁品牌素材的獨立圖片，不修改首頁構圖、不納入來源提交。
