# Hero：聆聽的河流

基準版本 3c1cdff6：https://7cdd6dbf.listenriver.pages.dev/ 。

將散落色暈重新構成河岸與透光河道：右側以霧藍形成水域，陶土分布在上方及右下岸邊；一條 S 形紙白留白穿過水色，像聆聽時保留的空間。三道細微的弧線沿河道回應，象徵聲音與漣漪。

- 水色 #608F9C，陶土 #CA947C，透光紙白 #FFFAF1，主標 #354E55。
- 桌面 Hero 高度 420px，增加河道的垂直轉折與呼吸空間；手機維持原有 280px 最小高度。
- 沿用靜態紙紋。河道使用單一靜態 SVG 局部柔化，沒有動態噪聲、JavaScript 或大型圖片。
- 既有動態河線降為背景，近景透明度 0.16、遠景 0.10；路徑及 12s / 17s 節奏維持。
- 深色模式另外使用低明度紙光與灰藍色，避免白色河道刺眼。
- 前版 SVG 保留，以 Git 與固定部署網址比較。下方首頁結構與樣式不變。

驗證：Hugo 建置成功，1440、808、390px 深淺模式皆無橫向溢出，原動畫秒數與減少動態效果設定正常。檢視截圖後將深色河道不透明度降為 0.35，避免發光帶過強。
